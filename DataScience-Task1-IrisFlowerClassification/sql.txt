Stored Procedure:
  are precompiled collections of one or more sql statements that can be executed as a unit , they help improve performance and security by encapsulating on the server side 

SYNTAX:
      CREATE PROCEDURE ProcedureName
      AS
      BEGIN
     -SQL STATEMENTS
      END;

Normalization
    is the process of organizing the fields and tables of a relational db.
    Types-1NF,2NF,3NF,BCNF.
    BCNF-a column or set of columns that can uniquely identify the rest of the columns.

          perform calculation across a set of table row related to the current row.They are powerfull for complex analytics and reports,the partition by clause in integral to window functions.
           .ROW_NUMBER().RANK(),DENSE_RANK()
           .LEAD(),LAG()
           .SUM(),OVER()
 
Syntax
         <window_function> OVER{
         PARTITION BY <expression>
         ORDER BY <expression>
