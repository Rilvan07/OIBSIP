\# Iris Flower Classification



\## 📌 Project Overview



This project is a Machine Learning classification project that predicts the species of an Iris flower based on its sepal and petal measurements.



The project uses the \*\*Iris dataset\*\* and applies \*\*Logistic Regression\*\* to classify flowers into three species:



\* Iris Setosa

\* Iris Versicolor

\* Iris Virginica



\## 🎯 Objective



The main objective of this project is to build a machine learning model that can accurately classify Iris flowers based on their:



\* Sepal Length

\* Sepal Width

\* Petal Length

\* Petal Width



\## 🛠️ Technologies Used



\* Python

\* Pandas

\* NumPy

\* Matplotlib

\* Seaborn

\* Scikit-learn

\* Jupyter Notebook



\## 🔍 Project Workflow



1\. Load the Iris dataset

2\. Explore and understand the dataset

3\. Perform data preprocessing

4\. Split the dataset into training and testing data

5\. Train the Logistic Regression model

6\. Make predictions

7\. Evaluate model performance

8\. Visualize the Confusion Matrix



\## 🤖 Machine Learning Algorithm



\*\*Logistic Regression\*\* is used as the classification algorithm to predict the species of Iris flowers.



\## 📊 Model Evaluation



The model performance is evaluated using:



\* Accuracy Score

\* Confusion Matrix

\* Classification Report
